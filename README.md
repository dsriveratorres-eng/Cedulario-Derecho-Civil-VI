# Cedulario Sucesorio

Tarjetas de estudio de Derecho Sucesorio (Derecho Civil VII): 326 preguntas de examen oral y 73 artículos del Código Civil para memorizar, con un plan de 14 días y repetición espaciada.

Es una sola página (`index.html`): no necesita servidor, base de datos ni compilación.

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `index.html` | La aplicación completa: tarjetas, plan y lógica de repaso. |
| `favicon.svg` | Ícono de la pestaña y del acceso directo en el celular. |
| `.nojekyll` | Le indica a GitHub Pages que publique los archivos tal cual, sin procesarlos. |
| `README.md` | Este archivo. |

## Publicar en GitHub Pages

1. Crea un repositorio nuevo (por ejemplo, `cedulario-sucesorio`).
2. Sube los cuatro archivos a la raíz del repositorio (*Add file → Upload files*). Ojo: `.nojekyll` empieza con punto y algunos sistemas lo ocultan; si no aparece al arrastrar, créalo con *Add file → Create new file* y déjalo vacío.
3. En el repositorio, entra a *Settings → Pages*. En *Build and deployment*, elige *Source: Deploy from a branch*, rama `main` y carpeta `/ (root)`, y guarda.
4. En uno o dos minutos la página queda en `https://TU-USUARIO.github.io/cedulario-sucesorio/`.

Con una cuenta gratuita, GitHub Pages solo publica repositorios públicos: cualquiera que tenga el enlace podrá ver las tarjetas.

## Dónde se guarda el progreso

En esta versión el avance se guarda en el navegador del dispositivo (almacenamiento local). Cada celular o computador lleva su propio progreso, y si borras los datos del sitio se pierde. Para estudiar en el celular, abre el enlace y usa *Agregar a pantalla de inicio*.

## Fuentes

Manual *Derecho Sucesorio* de Maricruz Gómez de la Torre, apunte «Sucesorio» de Naranjo (basado en Somarriva y Meza Barros) y Código Civil vigente (DFL 1 de 2000, versión de agosto de 2025).
